# ⚡ Quick Start Guide

## 🚀 3 Langkah Mudah

### 1️⃣ Install Dependencies
```powershell
npm install
```
Tunggu sampai selesai (2-5 menit).

### 2️⃣ Jalankan Server

**Cara Otomatis (Recommended):**
- Double-click file `start.bat`
- Akan membuka 2 terminal otomatis

**Atau Manual:**
```powershell
# Terminal 1 - Backend
npm run server

# Terminal 2 - Frontend (buka terminal baru)
npm run dev
```

### 3️⃣ Buka Browser
- Website: http://localhost:3000
- Admin: http://localhost:3000/admin/login

## ⚠️ Troubleshooting Cepat

### Backend gagal start?
- Port 5001 mungkin sudah digunakan
- Lihat file `TROUBLESHOOTING.md` untuk solusi lengkap

### Frontend tidak konek?
- Pastikan backend running (cek terminal 1)
- Gunakan URL: `http://localhost:3000` (bukan 127.0.0.1)

### Perubahan tidak tersimpan?
- Cek console browser (F12)
- Pastikan backend tidak error
